# Malinergy — L'énergie au Mali

> Une plateforme de connaissances pour tout ce qui concerne l'énergie au Mali — économie, ingénierie, actualités, gouvernance, communauté.

## Introduction

Malinergy est conçu comme une destination unique pour les sujets énergétiques au Mali, s'adressant aux investisseurs, décideurs, ingénieurs, étudiants et au grand public.

## Structure du site

- **Économie** : Tarifs, structures de marché, données financières de l'EDM-SA.
- **Ingénierie** : Diagrammes de réseau, cartes d'irradiation solaire, caractéristiques techniques.
- **Dernières publications** : Actualités sur les pannes, projets et réformes.
- **Données** : Chiffres clés du secteur en temps réel.

## Développement

Ce site est construit avec **React** et **Vite**.

### Installation

```bash
npm install
```

### Développement local

```bash
npm run dev
```

### Build de production

```bash
npm run build
```

## Design

Le design suit le **Malinergy Design System**, basé sur :
- **Couleurs** : Indigo, Ocre, Terres cuites.
- **Typographie** : Source Serif 4 (Titres), IBM Plex Sans (Corps), IBM Plex Mono (Données).
